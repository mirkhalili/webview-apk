# سامانه سخت‌افزار دانشگاه آزاد اسلامی واحد یزد

سامانه ماژولار PHP 8.2+/MySQL برای پایش و ثبت تجهیزات رایانه، چاپگر، نمایشگر و اسکنر.

## ساختار

- `app/` هسته برنامه، احراز هویت، مجوزها، کنترلرها و سرویس CSV
- `config/` تنظیمات و اتصال PDO
- `database/schema.sql` ساختار کامل پایگاه داده
- `public/` ورودی وب، CSS و JS
- `storage/uploads/` پیوست‌های بارگذاری‌شده
- `routes/` مسیرهای برنامه
- `views/` قالب‌های RTL

## نقش‌ها

`admin` مدیر، `collector` برداشت‌کننده، `viewer` مشاهده‌کننده، `expert` کارشناس.

## راه‌اندازی

1. PHP 8.2+ و MySQL 8+ تهیه کنید.
2. `database/schema.sql` را اجرا کنید.
3. مقادیر `config/config.php` را تنظیم کنید.
4. وب‌روت را روی `ihw/public` قرار دهید.
5. پوشه `storage/uploads` باید writable باشد.

> رمزهای نمونه فقط برای توسعه هستند و باید در اولین اجرا تغییر کنند.

## منبع فیلدها

فرم Word شامل مشخصات کامپیوتر، RAM اسلات‌به‌اسلات، شبکه و مشخصات چاپگر است. CSV ارسالی نیز 64 ستون فنی از ComputerName تا CollectedAt دارد. واردکننده CSV مقادیر چندتایی را با `|`، `,` و الگوهای رکوردی موجود در فایل تحلیل می‌کند و برای هاردها و RAM ساختار JSON نگه می‌دارد.
